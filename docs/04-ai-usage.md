# 工具使用与个人贡献

候选人实际个人投入为 2 小时 30 分钟，已由本人确认。候选人负责架构设计，包括原生 ReAct 循环、自建 Harness、工具边界、上下文预算和业务状态组织，并参与选题、模型选择和功能边界确定。

实现时使用 Codex 辅助完成代码、测试和文档。MiniMax-M3.1-Flash 用于真实模型验证。以下实现改动和验证由工具辅助完成。

- 增加补查后复审、缺项追问、证据冲突核实和带编号的改期确认。
- 为工具结果设置限长，增加上下文预算、历史压缩和超限状态。
- 用可执行测试及数据库查询验证正常排期、冲突、重复提交、授权校验和失败回滚。

运行记录区分真实模型调用与离线 Mock。Mock 用于验证流程和状态约束，真实模型 Trace 用于验证观察结果变化后的动作选择。候选人的个人贡献按架构与需求设计记录，实现和执行验证的辅助范围按上述内容披露。

# 需求

内容团队有一批候选素材，需要找出缺少信息或触发规则的素材，给出空闲发布时段，并把可确认的排期保存在草稿中。

- 输入使用素材 ID、素材元数据、硬性发布时间、既有排期、审核规则和可选补充证据。项目使用合成资料。改期确认由操作者通过输入提交。
- 输出逐项包含审核状态、风险及规则 ID、建议时段、待确认事项、草稿状态和运行记录。
- 单渠道按完整时段字符串判断占用。每批按输入顺序执行，已保存的草稿占用时段，待确认候选保持可用。项目写入本地草稿。
- 成功标准包括正常保存、信息不足时指出缺项、规则风险时阻断、冲突时提出经查询的替代时段并等待确认、重复提交时复用草稿、写入失败时明确报告并回滚。
- 在相同素材与时段要求下改变既有排期，真实模型观察到冲突后应能选择查询替代时段。每个素材最多执行八轮模型决策。
- 本地证据能补齐缺项时，复审结果决定能否排期。确认记录必须绑定素材、原时段和建议时段，且等待确认期间不占用排期。
- 本地证据不足时，Agent 可向操作者追问具体缺项。补齐后重新审核，追问期间不保存草稿。
- 同一字段的证据结论冲突时，输出相反结论及来源编号，等待核实后的资料，再重新审核。
